# Hospital & Doctor Appointment System

A full-stack production-ready Hospital & Doctor Appointment System built with React, Redux Toolkit, Tailwind CSS, and Supabase.

## Features
- **Patient Dashboard:** Search doctors with filters, book appointment slots, view medical records & prescriptions.
- **Doctor Dashboard:** Manage slots/availability, view patient appointments, write prescriptions.
- **Admin Dashboard:** Approve doctor registrations, view stats and charts, manage specializations.
- **Mock Payment:** Integrated Razorpay checkout simulation.
- **Authentication:** Role-based access control (Patient, Doctor, Admin).
